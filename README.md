# agent-memory-layer

코딩 에이전트의 기억을 사람이 읽는 파일로 두고, 기억이 남는 길과 쓰이는 길을 둘 다 사람이 볼 수 있게 하는 도구다. 설계를 한 번 갈아엎었고, 지금은 프로토타입을 만들기 전이다.

## 문제

에이전트가 쓰는 기억이 관리되지 않는다. 무엇이 언제 왜 남았는지 모르고, 파일이 흩어져 있고, 낡은 기억을 고치기 어렵고, 이번 세션에 무엇이 쓰였는지 모른다.

## 만드는 것

둘을 만들고, 둘 다 충족해야 한다.

| 쪽 | 무엇 | 충족 조건 |
|---|---|---|
| 저장 | 기억이 생겨서 제자리에 놓이고 고쳐지는 길 | 사람이 묻지 않고도 무엇이 언제 왜 남았는지 알고, 한 곳에서 찾고, 낡은 것을 말 한 번으로 고친다 |
| 활용 | 놓인 기억이 일하는 세션에 닿아서 답을 바꾸는 길 | 그 일에 필요한 기억이 닿고, 닿은 기억대로 하고, 엉뚱한 기억은 끼어들지 않는다 |

저장의 단위와 이름이 활용의 고르기를 정해서, 둘을 따로 만들지 않는다.

## 첫 목표

한 사이클이 도는 것이다.

| 걸음 | 하는 일 |
|---|---|
| 받기 | 이미 쌓인 기억을 사실 하나씩으로 나눠 받는다 |
| load | 세션이 시작할 때 그 일에 맞는 기억이 닿고, 닿은 것이 화면에 보인다 |
| 쓰기 | 새 기억이 남고, 언제 왜 남았는지가 로그에 적힌다 |
| 고치기 | 낡은 기억을 말 한 번으로 찾아 고친다 |

## 만드는 방식

- 빠르게 프로토타입을 만들고, 설계 글은 돌아가는 것을 따라 쓴다.
- 제약은 처음에 정하지 않는다. 한 사이클이 돈 뒤에 실제로 지켜진 것을 제약으로 적는다.
- 만드는 동안 지키는 것은 둘이다. 이미 쌓인 기억의 원본을 지우지 않고, 실제 home에 놓기 전에 격리된 home에서 먼저 돌린다.
- 원본을 사람이 읽는 markdown 파일로 두는 데서 출발한다.

Claude Code에서 먼저 만든다.
