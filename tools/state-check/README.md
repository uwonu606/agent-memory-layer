# state-check

기억의 상태 기계가 받아야 하는 경우를 다 받는지 잰다. 모델과 harness를 부르지 않고 Python 3 표준 라이브러리만 쓴다.

기계가 옮긴 설계는 [기억의 상태](../../docs/design/state.md), [저장](../../docs/design/storing.md), [활용](../../docs/design/using.md)에 있고, 낱말의 뜻은 [용어집](../../GLOSSARY.md)에 있다.

```
python3 check.py     # 경우 표현률, 불변식 위반, 도달한 상태
python3 mutants.py   # 일부러 망가뜨린 기계를 경우나 불변식이 잡는지
```

## 파일

| 파일 | 담은 것 |
|---|---|
| `machine.py` | 상태 기계 하나. 기억을 바꾸는 조작은 `capture`, `remember`, `forget`, `supersede`, `retire`, `restore`이고, 세션의 조작은 `open_session`, `load`, `compact`, `resume`, `check_evidence`다. `put_file`, `drop_file`, `advance`는 저장소의 파일과 날짜를 바꿔 근거와 기한을 시험한다 |
| `scenarios.py` | 경우 묶음. `IN`은 기계가 받아야 하는 경우, `OUT`은 다른 부품이 맡는 경우와 그 주인, `OPEN`은 기대를 아직 정하지 않은 경우다 |
| `check.py` | 경우를 돌리고, 무작위 조작 열을 돌려 불변식을 본다 |
| `mutants.py` | 기계를 한 곳씩 망가뜨린 변이를 돌려, 경우나 불변식이 깨지는지 본다 |

## 지표

| 지표 | 뜻 | 나아지는 쪽 |
|---|---|---|
| 경우 표현률 | `IN` 경우 가운데 기계가 기대대로 해낸 비율 | 모두 |
| 불변식 위반 | 무작위 2000회 × 40걸음 동안 깨진 불변식의 횟수 | 0 |
| 도달한 상태 | 무작위 조작으로 닿은 상태. 닿지 않는 상태가 있으면 그 상태로 가는 전이가 없다 | 모두 |
| 변이 검출 | 망가뜨린 기계를 경우나 불변식이 잡은 수 | 모두 |
| `OUT`과 `OPEN`의 수 | 기계 밖으로 넘긴 경우와 아직 정하지 않은 경우 | `OUT`마다 주인이 있을 것 |

## 불변식

무작위 scope는 저장소 하나, 사람, 저장소 둘, 일의 갈래이고, 사람의 "어디서나"도 섞는다.

| 번호 | 깨지면 |
|---|---|
| I1 | 끝난 기억이 세션에 실려 있다 |
| I2 | 출처가 바뀌었다 |
| I3 | 같은 주제·겹치는 scope에 살아 있는 기억이 둘이다 |
| I4 | 배경 정리가 사람이 정한 기억을 끝내거나 scope를 줄였다 |
| I5 | 상태·scope·근거·기한이 바뀌었는데 기록 줄이 없다 |
| I6 | 거절된 주제가 사람이 시키지 않았는데 다시 뽑혔다 |
| I7 | 근거가 어긋나거나 기한이 지난 기억이 실렸다 |
| I8 | 지금 상태가 아닌 기억에 기한이 있다 |
| I9 | scope가 빈 기억이 살아 있다 |
| I10 | 한 걸음에 같은 기억을 한 세션에 두 번 실었다 |
| I11 | 한 세션에 같은 주제의 기억이 둘 실려 있다 |
| I12 | agent의 말이나 고침이 사람이 정한 기억을 끝내거나 바꿨다 |

## 재는 범위

확인하는 것은 모델 없는 상태 기계가 이 경우들에서 기대대로 움직인다는 데까지다. 실제 harness에서 돌린 것이 아니다.

| 넣지 않은 것 | 지금 기계의 모습 |
|---|---|
| 문장을 조각으로 나누기 | 기억 하나의 문장을 통째로 다룬다 |
| 대상마다의 근거 | 근거 목록은 기억 하나에 한 벌이다. 기한만 대상마다 둔다 |
| 판을 두는 자리 | 끝난 판을 기계 안에 그대로 둔다. 설계는 끝난 판을 기록에 두지만, 기계는 어디에 두는지를 다루지 않는다 |
| 되돌린 scope가 물러난 기억의 scope보다 좁을 때 | 물러난 기억을 통째로 끝내고, 거절 표시는 남기지 않는다 |
| 지금 상태 기억의 기본 기한 | `TRANSIENT_DEFAULT_DAYS`(14일)는 정하지 않은 값의 자리만 채운 것이다 |

## 경우를 더하는 법

1. `scenarios.py`에 기계 하나를 받아 `(확인할 것, 맞았나)` 목록을 돌려주는 함수를 쓴다. 기대는 상태 이름이 아니라 보이는 행동(실린 목록, 살아 있는 기억, 막혔는지)으로 적는다.
2. `IN`에 `(번호, 출처, 함수)`를 더한다. 출처는 그 경우가 나온 문제 갈래의 이름과 장면이다.
3. 실패하면 `GAP_KIND`에 빈 곳의 종류(구조, 전이, 칸, 조건, 정하지 않음)를 적고, 상태 표를 다시 연다.
4. 새 규칙을 넣었으면 `mutants.py`에 그 규칙을 망가뜨린 변이를 하나 더해, 검증이 그것을 잡는지 본다.
