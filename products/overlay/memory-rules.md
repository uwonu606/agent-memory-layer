# auto memory를 쓰고 읽는 규칙

모든 저장소가 기억 폴더 하나를 같이 쓰고, 세션이 시작할 때는 색인 `MEMORY.md`의 줄만 보인다. 색인의 줄만 보고도 그 기억을 지금 저장소에서 쓰는지 가를 수 있어야, 한 저장소에만 준 말이 다른 저장소의 일에 쓰이지 않는다.

저장소 이름은 git 저장소 뿌리 폴더의 이름이다. worktree에서는 본 저장소의 폴더 이름을, git 밖에서는 세션을 연 폴더의 이름을 쓴다.

## 쓰거나 고칠 때

- 주제 파일(기억 하나를 담은 파일)의 frontmatter `metadata` 아래에 `repo: todo-app`, `everywhere: false`처럼 두 칸을 적는다. `repo`는 그 기억을 처음 남긴 저장소 이름이고, 고칠 때도 그대로 둔다. `everywhere`는 사람이 "어디서나", "모든 저장소에서"처럼 저장소를 넘겨 쓰라고 말했을 때만 `true`로 적고, 내용이 어디서나 맞아 보여도 그 말이 없으면 `false`다.
- scope는 `everywhere`가 `true`면 `everywhere`, 아니면 `repo`의 저장소 이름이다. 색인의 줄에는 `—` 바로 뒤에 `[scope]`를 적는다. `- [제목](파일.md) — [todo-app] 설명`이나 `- [제목](파일.md) — [everywhere] 설명`의 꼴이다.
- 기억에는 지금 작업의 상태가 바뀐 뒤에도 맞는 말만 쓴다. 진행 상황, 곧 바뀔 임시 상태, 그 상태일 때만 맞는 지시는 대화에만 두고, 한 세션에서 여러 번 들었어도 그렇게 한다. 작업이 끝나면 틀린 말이 되어 다음 일에 끼어들기 때문이다. 사람이 기억하라고, 또는 다음 세션으로 넘기라고 분명히 시킨 것은 쓴다.

## 읽어 쓸 때

지금 일에는 scope가 지금 저장소 이름이거나 `everywhere`인 기억만 쓴다. 나머지 기억은 사람이 그 저장소를 짚어 물을 때만 꺼내고, 그 저장소의 것이라고 밝힌다.
